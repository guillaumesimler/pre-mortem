# Changelog

Each version came from a run or a design session; the cause is given with the change. Run outputs are private and not published.

## v0.7.1 (2026-10-24)
- At least one persona on every side, however many people or teams write: the seats per side rise rather than the panel dropping out. The panel's value is that it says what the room does not; more human writers, sharing one culture and one boss, do not replace that.
- Teams on one side do not compare sheets. Rule 1 admits groups that talk within themselves, never across.
- Cause: the argument for mixed groups. Not yet run.

## v0.7.0
- Every output names the model behind the panel and the synthesis; a floor at the middle tier, below which outputs are marked.
- Role-only cards by default for real people; a portrait only on the user's explicit request, marked as such.
- [ASSUMED] limited to facts about the situation on the decision date.
- Every output states that the orchestrator saw every sheet and the key.
- Cause: run 8, the skill run on itself, then re-run on three model tiers. The core types held on every tier; the smallest tier invented named people, drifted off its seats and read the split between triumph and disaster as contradictions. While [ASSUMED] also covered invented future events, the thin-brief share moved from 14 to 22 of 23 points on identical input.

## v0.6.0
- Every point states an outcome and the mechanism that produced it; the synthesis groups by mechanism.
- The decision check: a run holds one decision, and comes back to the user when the plan holds several.
- Recordings may feed the brief and the writers.
- Specialist claims (law, tax, regulation, standards) always sit outside the brief and are marked.
- Four seats a side for a larger context; the thin-brief warning is computed; personal plans have their own section; the documents that would settle the run are listed after it; every checkpoint asks one question at most.
- Cause: runs 4 to 7. People write outcomes while personas write mechanisms, so the synthesis had split them by format rather than by substance.

## v0.5.0 and v0.5.1
- DD mode: the run inside an acquisition due diligence, with a fixed cast of seven, each card writing on both sides. It replaces the fully autonomous Version 2.
- v0.5.1 renumbers the runs. Cause: design; DD mode not yet run.

## v0.4.5
- Insider mode: role-only and portrait runs on one draw, and their difference.
- Cause: run 7, run 6 repeated with role-only cards. Every core type held; the mechanisms that vanished traced to the user's portraits, and the role-only writers found one the portraits had crowded out.

## v0.4.4
- No alternatives in a run; the side draw kept from the user; panel-only mode.
- Cause: run 6, a panel-only backtest on an acquisition, which found the leadership set-up the user had called the deal's original sin without being told.

## v0.4.3
- Each seat slide shows its writer's profile beside the points.
- Cause: run 5c. Runs 5 to 5c changed only the brief on a municipal building project; the subject owner's facts changed which questions the run asked, and of whom, not how many.

## v0.4.2
- The brief checkpoint asks what the user read and judged secondary.
- Cause: run 3, where the missed factor had been read and left out of the brief.

## v0.4.1 (2026-10-20)
- Invented events marked as well as figures; specialist claims flagged for a specialist; the user's traits kept at full strength.
- Cause: review of run 3.

## v0.4 (2026-10-20)
- Team first; factor titles; a cap on types; recount from the key; a rule for real people.
- Cause: run 3, a backtest on a real buy-out, which turned the deal's own terms into the failure mechanism the buyers had missed, and overstated one writer count.

## v0.3 (2026-10-20)
- Checks before committing first; one triumph and one disaster each; charts removed.
- Cause: run 2, which found all three of the class's factors and kept the panel's own; its grids were the hardest part to read.

## v0.3-pre (2026-10-20)
- Go to the extremes; insiders seated first.
- Cause: run 1 found the likely, manageable risks and missed what a class of students had found on the same case: the people at the top falling out, promises the product could not keep, a catastrophic product failure.
